Oracle EBS to AWS migration automation

An Ansible-based solution that cut EBS clone migration and provisioning from 48 hours to 4 hours per instance.

Tags

What it was

A proof of concept for migrating 60+ Oracle EBS instances (versions 11 and 12.1) from a private hosting solution to AWS.

What I did

I led development of an Ansible-based solution to automate migration of EBS environments from on-premises infrastructure to AWS. We built the AWS infrastructure from the ground up and, through a combination of Ansible, AWS Lambda and custom database replication scripts, executed the migration in under 48 hours with only a 2-hour downtime window.

Challenges

From designing the cloud infrastructure off the back of a private hosting solution, to using more advanced tooling to minimise infrastructure cost and scale it only when needed — one of the biggest (and more fun) challenges I had faced up to that point.

Outcome

Migration and provisioning time for EBS clones dropped from 48 hours to 4 hours per instance, and the POC infrastructure cost came in around 30% lower.
