Plataforma de atendentes virtuais

Assumi um programa em curso, reconstruí base de código e time, e entreguei a versão estabilizada em 3 meses. Hoje atende mais de 5.000 usuários.

Período
2025
Organização
Deloitte
Papel
Gerente Sênior

Tecnologias

  • Python
  • LLMs
  • orquestração multiagente

Tags

  • técnico
  • genai
  • entrega

O que era

Uma plataforma que permite a áreas de negócio criarem e operarem atendentes virtuais de chat sem depender de um time de engenharia para cada novo agente.

O que eu fiz

Assumi o projeto no meio do programa, após a saída do líder de entrega anterior, herdando uma base de código instável e um time fragmentado. Reconstruí ambos e entreguei a versão estabilizada em 3 meses com uma squad de 4 pessoas, trabalhando diretamente com o PO, o gerente e o diretor do cliente.

Resultado

A plataforma atende hoje mais de 5.000 usuários: agentes de chat padrão sobem com apenas uma revisão leve de engenharia, e agentes complexos aproveitam a base já construída. Devolvi a condução ao cliente para a versão final, conforme o planejado.
