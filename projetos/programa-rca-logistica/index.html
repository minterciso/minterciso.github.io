O que era

Um programa de automação cognitiva (RCA) para uma das maiores empresas de logística do Brasil, cobrindo o uso de estoque, a previsão de novos pedidos e a montagem de cargas.

O que eu fiz

Conduzi a entrega técnica de uma prova de conceito de seis meses até a produção, ao longo de múltiplas fases do projeto. A solução combinava:

  • RPA com Automation Anywhere
  • um daemon customizado em Python para orquestração
  • modelos de machine learning para apoio à decisão operacional
  • uma interface web para integração com o cliente

O problema do bin packing

A parte mais divertida foi uma variação do problema do bin packing. Como entusiasta de matemática, cheguei a uma solução viável por dois caminhos:

  • um algoritmo próprio, que iterava pelo estoque eliminando soluções inviáveis
  • um algoritmo genético, para otimizar a ordem e em qual carreta iria cada palete

Esse trabalho virou o artigo Usage of a genetic algorithm for optimizing stock usage, apresentado na GECCO 2020.

Resultado

Ganho anual estimado pelo cliente em R$ 500 milhões, com melhoria no escoamento de estoque, maior velocidade de entrega para grandes e médios varejistas e redução no tempo de montagem e validação de cargas.
