Automação de migração Oracle EBS para AWS

Solução baseada em Ansible que reduziu a migração e o provisionamento de clones EBS de 48 horas para 4 horas por instância.

Período
2017
Organização
Deloitte
Papel
DBA Oracle / ATG

Tecnologias

  • Ansible
  • AWS
  • Oracle EBS
  • Bash
  • AWS Lambda

Tags

  • técnico
  • infraestrutura
  • aws

O que era

Uma prova de conceito para migrar mais de 60 instâncias de Oracle EBS (versões 11 e 12.1) de uma solução de hosting privado para a AWS.

O que eu fiz

Liderei o desenvolvimento de uma solução baseada em Ansible para automatizar a migração de ambientes EBS de infraestrutura on-premises para a AWS. Criamos a infraestrutura AWS do zero e, com uma combinação de Ansible, AWS Lambda e scripts próprios de replicação de banco, executamos a migração em menos de 48 horas, com apenas 2 horas de janela de indisponibilidade.

Desafios

Desde desenhar a infraestrutura de nuvem a partir de uma solução de hosting privado até usar ferramentas mais avançadas para minimizar o custo da infraestrutura e escalá-la apenas quando necessário — foi um dos maiores (e mais divertidos) desafios que tive até então.

Resultado

O tempo de migração e provisionamento de clones EBS caiu de 48 horas para 4 horas por instância, e o custo da infraestrutura na POC ficou cerca de 30% menor.
